# Colis Connect

Application Flutter de démonstration (Expéditeur ↔ Livreur) : bordereaux avec code-barres, QR de clôture journalière, suivi des statuts (livré, retour provisoire, retour définitif).

Les données sont simulées (`MockDB`), il n'y a pas encore de serveur.

## Obtenir l'APK
1. Onglet **Actions** → dernier run « Build APK ».
2. Télécharger l'artefact `colis-connect-apk` (fichier `app-debug.apk`).
